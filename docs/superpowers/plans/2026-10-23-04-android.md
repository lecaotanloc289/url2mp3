# Plan 4 — Android app (spike folded in)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Executed by the
> agent that wrote it, in the same session.

**Goal:** The same Tauri app as an Android APK (arm64-v8a, armeabi-v7a), downloading on the
phone itself, installable from GitHub Releases.

## Findings that replace the spike

- `yausername/youtubedl-android` **0.18.1** (2025-11-16, JitPack) packages Python, yt-dlp,
  ffmpeg and — since that release — **QuickJS** as `.so` files in `nativeLibraryDir`, where
  Android allows execution. It runs yt-dlp as `libpython.so <noBackupFilesDir>/youtubedl-android/
  yt-dlp/yt-dlp <args>` with `LD_LIBRARY_PATH`, `SSL_CERT_FILE`, `PYTHONHOME`, `HOME`, `TMPDIR`,
  `PATH` set, and passes `--js-runtimes quickjs:<nativeLibraryDir>/libqjs.so`. (The JunkFood02
  fork used by Seal stopped in 2024, before yt-dlp needed a JS runtime.)
- So the Rust core can drive it unchanged once `Tools` can put arguments before yt-dlp's own.

## Design

- **core:** `Tools.ytdlp_args: Vec<OsString>` — arguments placed before every yt-dlp call
  (Android: the yt-dlp script path). Empty on desktop.
- **Kotlin plugin** `app/plugins/android-tools` (a local Tauri plugin crate, Android-only):
  - `prepare()` → runs `YoutubeDL.init` + `FFmpeg.init` (unpacks Python/ffmpeg on first run)
    and returns `{ python, ytdlpScript, ffmpeg, qjs, env, version }`.
  - `updateYtdlp()` → `YoutubeDL.updateYoutubeDL(STABLE)`, returns the new version.
  - `keepAlive(active: bool)` → starts/stops a foreground service (`dataSync`) with a
    notification while downloads run, so Android doesn't kill them in the background.
  - Share target: `ACTION_SEND text/plain` intents (YouTube/TikTok → Share → url2mp3) are
    emitted to the webview as `shared` events, also for the intent that launched the app.
- **Rust app:** `jobs.rs` gets a platform split: desktop keeps `Store`; Android builds `Tools`
  from `prepare()` and updates through the plugin. Output folder default on Android:
  `/storage/emulated/0/Download/url2mp3` — Download accepts any file type (our temp files),
  needs no permission on Android 11+ for files the app creates, and music players index it.
  `minSdk 30`.
- **UI:** on Android hide desktop-only settings (output folder picker, browser cookies, reveal
  button), call `keepAlive` when the active count goes 0↔n, handle `shared`.

## Steps

1. Toolchain: Android cmdline-tools + NDK, rustup Android targets, an arm64 emulator (AVD).
2. `tauri android init`; commit `gen/android` (manifest edits: `extractNativeLibs`, share
   intent filter, foreground service, `minSdk 30`).
3. core `ytdlp_args` + test (fake yt-dlp gets the prefix first).
4. Plugin crate + Kotlin; Rust Android branch in `jobs.rs`.
5. UI changes.
6. Build debug APK, install on the emulator, download a YouTube link, a TikTok link, a playlist
   (limit 3); share a link from a browser into the app; switch away during a download.
7. Release APK signed with a new keystore (kept outside the repo, path in `~/.url2mp3-keystore`,
   owner told to back it up); add to `release-local.sh`.
