# Plan 3 — CI and release builds (Windows, macOS, CLI)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Executed by the
> agent that wrote it, in the same session.

**Goal:** GitHub Actions checks every push and, on a `v*` tag, builds the Windows and macOS
apps plus CLI archives into a **draft** GitHub release the owner publishes by hand.

**Tech:** `tauri-apps/tauri-action@v1`, `dtolnay/rust-toolchain`, `Swatinem/rust-cache@v2`,
`pnpm/action-setup@v6`, `actions/setup-node@v7`, `actions/checkout@v7`, `gh` CLI.
The repo is public, so hosted runners are free.

## Files

| Path | Role |
|---|---|
| `.github/workflows/ci.yml` | push/PR: fmt, clippy, Rust tests, UI tests + build; macOS and Windows |
| `.github/workflows/release.yml` | tag `v*` (or manual run): app bundles + CLI archives |

## ci.yml

Matrix `macos-latest`, `windows-latest`. Steps: checkout → Rust stable (rustfmt, clippy) →
rust-cache → pnpm + Node 24 → `pnpm install --frozen-lockfile` → `pnpm sidecars` (tauri-build
refuses to compile without the `externalBin` files) → `pnpm test` → `pnpm build` →
`cargo fmt --all --check` → `cargo clippy --workspace --all-targets -- -D warnings` →
`cargo test --workspace`. Windows matters: it compiles the `cfg(windows)` code paths
(`CREATE_NO_WINDOW`, `seek_write`, `.exe` sidecars) that no Mac build sees.

## release.yml

- Trigger: `push: tags: ['v*']` and `workflow_dispatch`. A tag run creates/updates a draft
  release named `url2mp3 vX.Y.Z`; a manual run only uploads workflow artifacts (no release).
- `desktop` matrix: `aarch64-apple-darwin` and `x86_64-apple-darwin` on `macos-latest` (the
  Intel build is cross-compiled; its sidecars are the x86_64 pins), `x86_64-pc-windows-msvc` on
  `windows-latest`. Each: `pnpm sidecars <target>`, then tauri-action with
  `args: --target <target> --bundles <dmg | nsis,msi>`, `releaseDraft: true`,
  `uploadWorkflowArtifacts: true`.
- `cli` matrix (needs `desktop`): macOS arm64/x64, Windows x64, Linux x64 →
  `url2mp3-cli-<target>.tar.gz` / `.zip`; uploaded with `gh release upload` on tag runs,
  as workflow artifacts otherwise.
- Release body: what to download per platform and how to open an unsigned app the first time
  (macOS: right-click → Open, or System Settings → Privacy & Security → Open Anyway, or
  `xattr -cr /Applications/url2mp3.app`; Windows SmartScreen: More info → Run anyway).

The tag must match the version in `Cargo.toml` (`[workspace.package] version`), which Tauri uses
for file names. Bumping to `0.2.0` happens in plan 6.

## Verification

- Push the branch → `ci` green on both OSes.
- `gh workflow run release.yml --ref feat/apps` → three app artifacts (two dmg, setup.exe + msi)
  and four CLI archives; download the arm64 dmg, open it, run a download.
